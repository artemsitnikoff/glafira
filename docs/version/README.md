# История релизов «Глафира Рекрутёр»

Один файл на релиз: `vX.Y.Z.md` — номер версии, дата и что сделали (кратко, по сути).
Версия = `frontend/src/lib/version.ts` (`APP_VERSION`).

**Правило (см. CLAUDE.md §6/§8):** на КАЖДЫЙ bump `APP_VERSION` создаётся файл
`docs/version/vX.Y.Z.md`. Делать всегда, вместе с bump'ом и коммитом релиза.

История эр до v1.4.0 (0.x–1.3.x) — в разделе «Свежие фичи» CLAUDE.md.
