# v1.8.5 — Фикс 500 при создании вакансии с кастомной воронкой (2026-09-23)

Жалоба клиента: ошибка сервера при заведении вакансии.

- **Причина:** CHECK-констрейнт `check_funnel_template` на `vacancies` разрешал `funnel_template` только из `('default','mass','technical','sales')`. Но форма вакансии шлёт **id кастомного пресета воронки** (таблица `funnel_templates`, UUID), когда пользователь выбирает свою воронку из Настроек → вставка падала на `CheckViolationError` → **500** (`services/vacancy.py:408` при flush).
- **Фикс:** миграция `e7f8a9b0c1d2` снимает `check_funnel_template` (`DROP CONSTRAINT IF EXISTS`, идемпотентно); CheckConstraint убран из модели `models/vacancy.py`. Воронки настраиваемые — жёсткий список значений устарел.
- **Безопасность:** этапы при кастомном шаблоне приходят готовыми из формы (path 1 в `create_vacancy`), `get_stages_for_template` не вызывается; а для неизвестного значения он безопасно фолбэчит на `'default'` (`core/stages.py`) — вторичных сбоев нет.
- Голова alembic до фикса — `c3e4f5a6b7c8` (сверено `alembic heads`/`current`); новая голова `e7f8a9b0c1d2`.
