# v1.12.0 — Настройки→AI: динамический список моделей из OpenRouter + цена за резюме (2026-10-18)

Устаревший статический whitelist LLM-моделей заменён на **живой каталог OpenRouter** с оценкой стоимости одной оценки резюме.

- **Бэкенд** (`services/glafira/models.py` переписан): `fetch_openrouter_models()` тянет публичный `GET {OPENROUTER_BASE_URL}/models` (без ключа, таймаут 10с, in-memory кэш ~1ч, graceful → кэш/{} при сбое). `cost_estimate()` — оценка за резюме (константы `SCORING_EST_PROMPT_TOKENS=4500`/`SCORING_EST_COMPLETION_TOKENS=900`/`USD_RUB_RATE=100`, помечено «ОЦЕНКА, не биллинг»). `get_model_options()` — рекомендованный шорт-лист (8 моделей: deepseek-v4-flash, claude-haiku-5.5, gemini-3.1-flash-lite, glm-5.2, kimi-k2.6, qwen3.7-max, claude-sonnet-5.5, claude-opus-5.5) с live-ценой. `search_models()` — поиск по всему каталогу. `is_valid_model()` — валидация по live-каталогу (fallback на recommended при недоступности OpenRouter). Статический `ALLOWED_LLM_MODELS` удалён, `ALLOWED_MODEL_VALUES` оставлен пустым shim'ом (импортит суперадминка).
- **API** (`api/v1/settings.py`): `GET /settings/ai-model` отдаёт options с `cost_usd/cost_rub/context_length`; новый `GET /settings/ai-model/search?q=`; `PATCH /settings/ai-model` валидирует по live-каталогу вместо статического set.
- **Резолв** (`services/settings/glafira.py::get_company_llm_model`): без whitelist-гейта — сохранённая модель компании возвращается как есть (провалидирована при сохранении), иначе env `GLAFIRA_MODEL`, иначе `DEFAULT_MODEL`. Скоринг-хотпас по-прежнему без сети.
- **config**: `GLAFIRA_MODEL` → `anthropic/claude-sonnet-5.5` (старый slug `claude-sonnet-4-6` с дефисом был невалиден для OpenRouter).
- **Фронт** (`SettingsAI.tsx`/`.css`/`useAiModel.ts`): шорт-лист радио-карточками с «≈ ₽ за резюме» + контекст, блок «Другая модель» (поиск с debounce по всему каталогу), честная оговорка «≈ оценка… не точный биллинг» (§0). Поле ключа OpenRouter сохранено.
- **Суперадминка**: `available_models` → рекомендованный шорт-лист (вместо пустого после удаления whitelist).
- Тесты: `test_ai_model_settings.py` переписан/расширен (GET с ценой, PATCH live-валидация, поиск, helper'ы); conftest мокает `fetch_openrouter_models` (offline). Прогон на VPS.

⚠️ Цена за резюме — ОЦЕНКА (токен-прикидка + курс ~100₽/$), не точный биллинг; в UI с «≈» и пояснением.
