# v1.12.1 — HOTFIX: greenlet (прод-бэкенд падал на старте после v1.12.0) (2026-10-18)

Пересборка backend на v1.12.0 поймала граблю §6: свежий pip НЕ тянет `greenlet` (раньше шёл транзитивно через sqlalchemy) → `ImportError: SQLAlchemy asyncio requires greenlet` на старте uvicorn → child-процессы умирали, `/api` отдавал 502 (фронт-статика жила). Предупреждение об этом было в памяти (glafira-nso уже пофикшен) — main словил при первой пересборке.

- `backend/requirements.txt`: `sqlalchemy>=2.0.23` → `sqlalchemy[asyncio]>=2.0.23` + явный `greenlet>=3.0.0` (тот же фикс, что в glafira-nso v1.11.x).
- Передеплой → backend поднялся, `/api` 200.
