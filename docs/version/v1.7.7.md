# v1.7.7 — Talantix: джоба догрузки недостающих кандидатов (2026-08-17)

При большом импорте ~375 персон упали транзиентно (блип БД под нагрузкой) — в базе их
нет. Пример: person 143944527 (создан вручную при разборе).

- **Новая джоба** `app/jobs/create_missing_talantix.py`: перечисляет всех персон Talantix,
  берёт множество уже известных `talantix_person_id` в базе (ЛЮБОЙ source — созданные +
  контакт-совпавшие potok/hh, которым id проставлен при импорте) и создаёт ТОЛЬКО тех,
  кого нет. Фетчит лишь реально отсутствующих (~375), не перебирает всю базу.
- Создание — штатным `_process_talantix_person` (skip-режим): полное резюме
  (Structured/Custom) + комментарии + согласие. Идемпотентно (созданные обретают
  talantix_person_id и уходят из «missing»). Параллельно (semaphore), company-scoped.
- Разовая, НЕ крон. ⚠️ Не запускать поверх идущего импорта.

**Запуск (VPS):**
```
cd /var/www/glafira && docker compose -f docker-compose.prod.yml run --rm backend \
  python -m app.jobs.create_missing_talantix 2>&1 | tee -a talantix-missing.log
```

Состояние базы Talantix после эры v1.7.3-1.7.6: 42 725 кандидатов — 28 883 со структурным
опытом, 12 100 с текстом резюме (CustomResume), 1 742 без резюме на Talantix.
