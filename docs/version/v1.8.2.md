# v1.8.2 — Фикс 500 на экспорте резюме PDF (длинное описание опыта) (2026-09-22)

Жалоба: `GET /candidates/{id}/resume?format=pdf` → 500.

- **Причина:** у кандидата опыт с длинным описанием (~2300 симв.). Каждый опыт рендерился как `Table(colWidths=[3cm,13cm])` (период | контент) и оборачивался в `KeepTogether`. Длинное описание делало ОДНУ строку таблицы выше страницы (750pt > usable ~714pt), а одну строку reportlab по умолчанию не разбивает между страницами; `KeepTogether` усугублял, запрещая разрыв вовсе → `reportlab LayoutError` → 500. (`services/resume_export.py`, `build_resume_pdf`.)
- **Фикс:** убран `KeepTogether`; таблице опыта задан **`splitInRow=1`** (reportlab 5.0.1 поддерживает) — правая ячейка = список абзацев (разбиваемые), период слева короткий → строка корректно перетекает между страницами.
- **Проверено на РЕАЛЬНОМ кандидате** (тот, что валил 500): PDF собирается, 57891 байт, сигнатура `%PDF-`. +регресс-тест `test_build_resume_pdf_long_experience_description` (опыт с ~40 абзацами → PDF без LayoutError).
- DOCX-путь не затронут (Word сам переносит).
