# v1.10.3 — DaData: логировать тело ошибки (диагностика 403) (2026-09-29)

Диагностика жалобы «контакты в верификации — Не удалось проверить».

- **Причина (не код):** DaData отдаёт `403 "Feature 'CLEAN' disabled for token …"` + `balance: 0.0`. Ключи валидны (эндпоинт баланса отвечает 200), но на токене **отключена услуга «Стандартизация» (Clean API)**. Правится в кабинете DaData (включить Стандартизацию / пополнить баланс). Код отработал честно — «Не удалось проверить», без фейк-вердикта (§0); заработает сам после включения CLEAN.
- **Правка кода (диагностика на будущее):** `services/dadata.py` — в `clean_phone/email/name` при ошибке теперь логируется ТЕЛО ответа DaData (`e.response.text`, до 300 симв.), а не только статус. Раньше в логах было бесполезное «403 » без причины.
