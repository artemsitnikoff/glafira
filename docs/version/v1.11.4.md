# v1.11.4 — Верификация: алименты + розыск ФССП + розыск МВД; убраны заглушки «в разработке» (2026-09-29)

По просьбе заказчика подключены все проверки provider parser-api, доступные по данным кандидата (ФИО + дата рождения), и убраны заглушки «в разработке».

**Новые РЕАЛЬНЫЕ блоки верификации:**
- **Алименты** (`fssp_alim_api/`) — задолженность по алиментам (ФССП), по ФИО+ДР.
- **Розыск ФССП** (`fssp_search_api/`) — реестр розыска должников по исполнительным производствам, по ФИО (ДР не требуется).
- **Розыск МВД** (`mvd_wanted_api/`) — база розыска МВД, по ФИО+ДР (дата рождения уходит в формате YYYY-MM-DD).

**Убраны неработающие заглушки** (не показываем «в разработке» — §0): «Проверка ИНН» (провайдер `nalog_inn` требует паспорт серия+номер, которых нет в карточке), «Реестр банкротов» (ЕФРСБ — провайдер не предоставляет), «Прочие реестры» (Росреестр/ЕГРН — нужен адрес).

**Код:**
- `services/fssp.py` — общий транспорт `_parser_get` (успех = `done==1` ИЛИ `success==1`), 3 новые `search_*` + нормализаторы (`_normalize_wanted_fssp`, `_normalize_mvd`); `_api_root()` бьёт в соседние модули провайдера от одного `FSSP_API_BASE`.
- `services/glafira/verify.py` — унифицированные хелперы блоков (`_provider_off_block`/`_needs_dob_block`/`_registry_result_block`), 4 блока (fssp/alimony/fssp_wanted/mvd_wanted); `_build_government_stub_blocks` удалён.
- Фронт `VerificationTab.tsx` — общий `renderRegistryItems` (поля по порядку) для всех реестровых блоков; иконки новых блоков.

**Гарантии те же:** token-gated (нет `FSSP_API_KEY` → честная заглушка «Не подключено», ничего наружу) + consent-gated (152-ФЗ, только после подписи ПдН). Результат — ВОЗМОЖНЫЕ совпадения по ФИО(+ДР), НЕ вердикт: плашка про однофамильца, `warn` (не «риск»); 0 записей → «Не найдено»; сбой/лимит → «Не удалось проверить» (не «чисто»).

**Не подключено (нужны доп. данные, не фейк):** ИНН/СНИЛС (паспорт/СНИЛС), штрафы ГИБДД (ВУ/СТС/УИН), проверка авто ГИБДД (VIN), ЕГРН/Росреестр (адрес), ЕГРЮЛ/ЕГРИП (ИНН/наименование). Можно добавить, если собирать эти поля в карточке.

Тесты обновлены (набор блоков) и дополнены (алименты/розыск-ФССП/розыск-МВД: парсинг, форматы, состояния блоков). Прогон — на VPS.
