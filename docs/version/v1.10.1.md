# v1.10.1 — Плашка «Формат занятости» в форме вакансии + бейдж «иногородний» (2026-09-28)

Фронт к бэкенд-полю `work_format` (v1.10.0). Рекрутёр задаёт формат занятости в форме
вакансии; на офисных вакансиях иногородние кандидаты помечаются мягким хинтом.

## Что сделано
- **Форма вакансии (`VacancyFormPage.tsx`), шаг «Описание»:** сразу после плашки «Тип занятости»
  добавлена плашка **«Формат занятости»** — те же чипы `.nv-segmented` 1:1 по стилю:
  Офис / Удалёнка / Гибрид. Поле опциональное: по умолчанию НЕ выбрано (`null`), в отличие от
  `employment_type` (дефолт `full`). Повторный клик по активному чипу снимает выбор (возврат к `null`).
  - Локальный тип формы `VacancyFormData` расширен `work_format: 'office'|'remote'|'hybrid'|null`
    (openapi протух → локальный тип + as-cast, как для полей автоматизации).
  - Create: `work_format: null`; edit: `work_format ?? null` из загруженной вакансии.
  - Отправка: `work_format` уходит в payload create И update через существующий `...formData`
    spread (тот же механизм, что и `employment_type`); значение ограничено enum/`null` самим UI —
    мусор не отправляется.
- **Бейдж «иногородний» (минимальная пометка, не фильтр):** показывается, когда вакансия
  `work_format === 'office'`, у вакансии И у кандидата заполнены города и они РАЗНЫЕ
  (сравнение нормализованное: trim + lower). Приглушённый серый пилюль (токены
  `--bg-3-hover` / `--fg-2` / `--radius-sm`), title-подсказка «Формат — офис, город кандидата
  отличается от города вакансии».
  - В строке кандидата воронки (`FunnelTable.tsx` → `FunnelRow`, в ячейке «Город»): вакансия
    (город + формат) прокинута из `VacancyDetailPage`.
  - В шапке карточки соискателя (`CandidateHeader.tsx`, строка контекста): формат/город вакансии
    берутся через `useVacancy(vacancyId)` — тот же queryKey `['vacancies', id]`, что уже загружен
    на странице воронки, поэтому из кеша без второго HTTP-запроса. В пуле (`vacancyId` не задан) —
    запрос выключен, бейдж не рендерится.
- **Шапка вакансии (`VacancyHeader.tsx`):** в мета-строке рядом с городом показывается
  «Формат: Офис/Удалёнка/Гибрид» (когда `work_format` задан).
