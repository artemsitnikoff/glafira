# v1.6.4 — Настоящий фикс greenlet + диаг (2026-08-14)

- Корень greenlet-варнинга: в `score_pending.main()` блок `async with async_session()`
  оборачивал ТОЛЬКО цикл оценки, а фазы auto_qa/интервью/тестов стояли ПОСЛЕ выхода из
  блока и дёргали `session.execute` на ЗАКРЫТОЙ сессии → соединение бралось и не
  возвращалось → варнинг на КАЖДОМ прогоне (даже пустом). Все фазы занесены внутрь
  `async with session`.
- Диаг `hh_diag_negotiation` научился принимать candidate_id (не только hh_id), берёт
  токен правильной компании и печатает полный ответ hh (actions[]/resume/…).
