# v1.8.3 — Суперадминка: удаление компании со всеми объектами (2026-09-22)

В `/super/` (карточка компании → «Опасная зона») можно полностью и необратимо удалить компанию со ВСЕМИ её данными.

- **Метод** `CompanyService.delete_company` (`backend/superadmin/service.py`): авто-обнаружение всех таблиц с `company_id` через `information_schema` (устойчиво к новым таблицам), удаление в ОДНОЙ транзакции. Порядок FK разрешается авто-ретраем с savepoint'ами: таблица, чью DELETE блокирует RESTRICT (напр. `employees→candidates`, `*_search_runs→vacancies`), откладывается и удаляется следующим проходом. `candidates.duplicate_of` обнуляется первым; дети без `company_id` (`stage_history`, `funnel_template_stages`) уходят каскадом с родителями; строка `companies` — последней. Любой сбой → полный откат (частичного удаления не бывает). Строго ОДНА company_id — чужие компании не затрагиваются.
- **Роут** `POST /super/companies/{id}/delete` (`main.py`): удаление только при ТОЧНОМ вводе названия компании (`confirm_name`) + JS-confirm. Иначе — отмена.
- **UI:** «Опасная зона» в карточке компании (`company_form.html`) — предупреждение со счётчиками (кандидаты/вакансии/пользователи), поле ввода названия, красная кнопка. Баннер success/error на дашборде.
- **Проверено на ПРОДЕ на одноразовой компании:** создана dummy-компания с объектами (кандидат/сотрудник/коммент/тег + провижининг) → удалена (32 записи), все объекты вычищены, **счётчики всех прочих 7 компаний не изменились** (изоляция), компания исчезла. Реальные компании не трогались.
- ⚠️ Необратимо. Перед удалением реальной компании — бэкап БД (`scripts/backup_db.sh`).
