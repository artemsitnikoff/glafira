# v1.7.16 — Хабр: логи импорта + крон в справочник (2026-08-20)

Довеска к Habr-эре: диагностика и автоматика.

- **Логи импорта** (`import_habr_response`): по каждому отклику — `rid`, `login`,
  created/updated, счётчики опыт/навыки/образование, найдены ли контакты (тел/email).
  Без PII (значения контактов НЕ пишем; логин Хабра публичен). Раньше в этом пути
  лог был только на сбой профиля — теперь видно, что реально импортнулось.
- **Крон Хабра в `deploy/crontab.txt`** (был пропущен!): `*/5` `poll_habr_responses`.
  ⚠️ Кроны на VPS заводятся руками — эта строка НЕ была в боевом crontab, поэтому
  новые отклики Хабра НЕ подтягивались автоматически (только кнопкой «Проверить»).
  Строку добавить в crontab deploy-пользователя (сделано в этой сессии по SSH).
