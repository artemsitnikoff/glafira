# v1.7.13 — Хабр: ссылка на профиль кандидата на карточке (2026-08-20)

Запрос: «Источник: Хабр Карьера» на карточке — сделать кликабельным на резюме/профиль
кандидата на Хабре.

Механизм ссылки-источника уже есть (`CandidateHeader` рендерит `source_url` кнопкой
«Открыть на hh.ru / Открыть оригинал»), у Habr-кандидатов просто не был заполнен
`source_url`.

- **Бек** (`import_habr_response`): ставит `candidate.source_url =
  https://career.habr.com/{login}` (login = external_id). Заполняется и новым, и при
  ре-синке существующих.
- **Фронт** (`CandidateHeader`): лейбл кнопки для `source='habr'` → «Открыть на Хабр Карьере».
- Уже импортированным 39 — проставить `source_url` разовым UPDATE (без ре-фетча):
  `UPDATE candidates SET source_url='https://career.habr.com/'||external_id
   WHERE source='habr' AND external_id IS NOT NULL AND coalesce(source_url,'')=''`.
