# v1.7.14 — Хабр: полное резюме + контакты из профиля /users/{login} (2026-08-20)

Отклик Хабра тонкий: отдаёт только ОДНУ (текущую) работу и БЕЗ контактов. У кандидата
на Хабре 8 мест работы, образование, телефон/email — в карточку попадало только «Ростелеком».

**Вскрыто пробингом:** полный профиль `GET /users/{login}` — **БЕСПЛАТНЫЙ** и богатый:
`experiences[]` (весь опыт, реальные `start_date`/`end_date`/`company_name`/`position`/
`description`/`skills`), `university_educations[]`+`college_educations[]`, `skills[]`,
`salary{from,currency}`, `resume_headline`/`specializations`, и **`contacts{phones,emails,
messengers}` с contactsAvailable** — контакты откликнувшегося доступны без платной кнопки.

**Фикс `import_habr_response`:** после привязки отклика тянет полный профиль (graceful —
недоступен → фолбэк на отклик) и берёт из него **резюме** (весь опыт с корректными
периодами `YYYY-MM — …`, образование, навыки, зарплата, должность) + **контакты**
(телефон нормализуется, email, мессенджеры в extra). Раз контакты пришли бесплатно —
проставляем `habr_contacts_opened_at` (платная кнопка «Открыть контакты» больше не нужна).
Дедуп теперь по телефону/email (тот же человек мог прийти из hh). ФИО — по-прежнему из
отклика (стабильный порядок «Фамилия Имя»). Новый маппер `_habr_profile_to_normalized` +2 теста.

Уже импортированным 39 — разовый ре-синк (re-import перечитывает профиль).
