# v1.8.4 — Смена пароля пользователя из настроек команды (2026-09-22)

Админ может сменить пароль любому пользователю Глафиры прямо из Настройки → Команда/Доступ.

- **Меню действий пользователя** (`UserActionMenu.tsx`): рядом с «Заблокировать/Активировать» и «Удалить» добавлен пункт **«Сменить пароль»** (иконка `lock`). Видимость и `disabled` — как у «Удалить»: пункт недоступен для самого себя (`isCurrentUser`).
- **Модалка** (inline, по образцу confirm-модалки удаления — те же классы `user-menu-content confirm` / `confirm-text` / `confirm-actions`): заголовок «Сменить пароль — {ФИО}», два поля пароля («Новый пароль» + «Повторите пароль»), чекбокс «Показать пароль», кнопки «Отмена» / «Сохранить».
- **Клиентская проверка** до отправки: пароль короче 6 символов или пароли не совпадают → инлайн-подсказка, запрос не уходит.
- **Мутация** `useSetUserPassword` (`api/mutations/settings.ts`): `POST /users/{id}/set-password` `{ password }` → инвалидирует `['users']` (как `useUpdateUser`/`useDeleteUser`). Ошибка сервера прокидывается в существующий `onError` (баннер на странице).
- Бэкенд готов заранее: `POST /users/{id}/set-password`, только admin, company-scoped, пароль <6 → 400 в конверте `{error:{code,message}}`.
- Новых глобальных CSS-классов нет: добавлены scoped `.pwd-input` / `.pwd-show` / `.pwd-hint` в `UserActionMenu.css` на реальных токенах.
