# v1.6.8 — Многострочный ввод в чате (2026-08-14)

Заказчик: в чате с кандидатом ввод был однострочный, Enter (в любом сочетании) сразу
отправлял сообщение → нельзя набрать абзац / доредактировать вставленный шаблон, писать
«в строчку» супер-медленно.

- Композер (ОБЩИЙ для попапа «Чаты» и вкладки «Чат» карточки — один компонент) переведён
  с `<input>` на авто-растущий `<textarea>`.
- **Enter = новая строка** (Shift+Enter тоже), **отправка — Ctrl+Enter / Cmd+Enter** и
  кнопкой «Отправить». Авто-высота до 140px, дальше внутренний скролл; после отправки
  схлопывается в 1 строку; корректно растёт при вставке готового шаблона.
- Подсказка под вводом: «Ctrl+Enter — отправить · Enter — новая строка».
- Файлы: `components/chat/ChatThread.tsx`, `ChatConversation.tsx`, `styles/chat.css`.
