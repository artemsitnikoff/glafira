# v1.7.1 — Talantix: подключение вставкой JSON токена (2026-08-15)

Упрощение подключения Talantix (фикс-форвард к v1.7.0).

- Вместо двух полей (refresh_token + access_token) — **ОДНО поле-textarea**: вставить
  весь JSON токенов из ЛК Talantix (ЛК → Мой профиль → API → Новый токен → скопировать
  весь JSON `{access_token, refresh_token, expires_in, created_at, …}` со страницы токена).
  Бэкенд парсит JSON → берёт `access_token` + `refresh_token` + срок.
- ⚠️ Вставить саму ССЫЛКУ на страницу токена нельзя: страница — SPA, сервер токенов из
  неё не получает (проверено — GET отдаёт HTML-шелл). При вставке ссылки — честная **400**
  «откройте в браузере и вставьте JSON целиком», а не фейк-«подключено».
- **Access-first валидация:** пастнутый свежий `access_token` проверяется лёгким GraphQL
  (`persons first:1`, `probe_access_token`) БЕЗ refresh → свежий одноразовый refresh не
  ротируется зря. Access невалиден/не передан → фолбэк на обмен refresh_token.
- Закрыто §0-замечание ревью v1.7.0: `access_token` больше не принимается-и-теряется молча.
- Контракт: `POST /candidates/import/talantix/connect` тело `{ "token": str }` (JSON или
  голый refresh_token). Файлы: talantix/{service,client}.py, schemas/talantix_import.py,
  candidate_import.py; ImportCandidatesWizard.tsx, useCandidateImport.ts.
