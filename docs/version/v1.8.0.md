# v1.8.0 — Импорт анонимных вакансий работодателя с hh (2026-09-21)

Работодатели публикуют часть вакансий **анонимно** (`type=anonymous` — работодатель скрыт
от соискателей). Публичный поиск `GET /vacancies?employer_id=` (`get_employer_vacancies`)
такие вакансии к работодателю НЕ привязывает → в фиче «Показать вакансии с hh»
(Настройки → Интеграции) они не показывались и не импортировались. Теперь показываются
и импортируются.

## Что сделали
- **Новая клиент-функция** `hh/client.py::get_manager_active_vacancies(access_token,
  employer_id, manager_id=None, page=0, per_page=50)` — `GET /employers/{id}/vacancies/active`
  (эндпоинт УПРАВЛЕНИЯ, отдаёт И анонимные). Собирает все страницы одним вызовом
  (предохранитель ≤ 20 страниц, `per_page` кап 50 — иначе hh 400). Листинг своих
  вакансий БЕСПЛАТНО. Graceful: сетевой/HTTP-сбой → `ValidationError` (как у соседей).
  `manager_id` опционален — по умолчанию hh берёт текущего менеджера токена (достаточно).
- **Мерж списков в `list_hh_vacancies`** (роут `GET /integrations/hh/vacancies`): тянем И
  публичный поиск (как раньше), И управляющий эндпоинт; мержим по `id` (dedup). В каждый
  элемент добавлены поля **`type`** ('open'/'anonymous'/…) и **`is_anonymous`**
  (`type=='anonymous'`) рядом с существующим `linked`. Fail-soft: сбой управляющего
  эндпоинта не роняет список — деградируем к публичному (прежнее поведение).
- **Импорт «Создать все новые»** (`import_hh_vacancies`, ветка `ids=None`): дискаверинг
  id теперь из ДВУХ источников (публичный + управляющий, dedup) → анонимные вакансии
  тоже подхватываются. Ветка с явными `hh_vacancy_ids` не менялась; маппинг вакансии
  (`get_vacancy_by_id`) не использует `employer.name`, поэтому анонимная импортируется
  без правок. Отклики к анонимной придут тем же кроном `poll_hh_responses` (не тронут).

## Схемы / фронт
- У роута `GET /integrations/hh/vacancies` **нет Pydantic-`response_model`** (отдаёт
  список dict напрямую) — новые ключи `type`/`is_anonymous` аддитивны, старый фронт не
  ломается. `contracts/openapi.json` протух — НЕ регенерён.
- TS-интерфейс `HhVacancy` (`frontend/src/api/hooks/useHhIntegration.ts`) дополнен
  опциональными `type?: string | null` и `is_anonymous?: boolean`.
