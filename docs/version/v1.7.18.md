# v1.7.18 — Демо-маскировка ПДн для показа/записи экрана (2026-08-24)

Для тестового показа с записью экрана на вакансии `cfbf5cd5-…` нужно скрыть ПДн
кандидатов (ФИО, телефон, email и пр.) — только на фронте, только для этой вакансии.

- **`lib/demoMask.ts`**: `demoMaskActive()` (true, если открыт `/vacancies/{demo-id}/…`)
  + `maskPiiDeep()` — рекурсивно маскирует в ответе API: ФИО → фейковые (детерминированно
  по исходному имени, пул из 10), телефон → `+7 (XXX) XXX-XX-XX`, email → `скрыто@demo.local`,
  avatar/photo → скрыто (инициалы), birth_date/messengers/source_url — обнуляются. Список
  демо-вакансий — константа `DEMO_VACANCY_IDS`.
- **`client.ts`**: response-интерцептор axios маскирует `response.data`, только пока открыта
  демо-вакансия и НЕ для `/auth/*` (имя залогиненного рекрутёра в сайдбаре — настоящее).
- ⚠️ **Только отображение** — в БД ничего не меняется; другие вакансии/страницы — реальные данные.
- ⚠️ Маскировка срабатывает на СЕТЕВЫХ ответах: на демо-вакансии сделать **Ctrl+Shift+R**,
  чтобы данные перезапросились из сети (иначе часть может отдаться из кэша немаскированной).
  После показа — обычный релоад на другой странице вернёт реальные данные.
