# v1.7.20 — Демо-маскировка: один фейк ФИО на пол (список=карточка) (2026-08-24)

Жалоба: фейковое ФИО в списке воронки ≠ в карточке кандидата. Причина — пул фейков
выбирался хешем, а сид в списке (из full_name) и карточке (из first+last) был разный.

Фикс: убран пул, теперь ОДИН фейк на пол — муж «Иванов Иван Иванович», жен «Дементьева
Глафира Ивановна». Пол определяется по ИСХОДНОМУ ФИО (скан токенов: отчество вна/вич +
женские окончания фамилии), НЕ по полю gender (его нет в строке списка). Список и карточка
держат одно full_name → пол одинаков → фейк совпадает. Определение устойчиво к порядку
токенов («Зайцева Мария Ивановна» и «Мария Зайцева» → оба жен). Остальное как в v1.7.18-19.
