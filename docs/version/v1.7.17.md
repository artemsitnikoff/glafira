# v1.7.17 — Суперадминка: сброс пароля админа компании (2026-08-20)

Запрос: завели новую компанию, забыли пароль админа, а сбросить его в `/super/`
было нельзя.

- **Сервис** `CompanyService.reset_admin_password(company_id, new_password=None)`:
  сбрасывает пароль ПЕРВОГО админа компании (по email — тот же, что в списке).
  Пусто → генерирует надёжный (`secrets.token_urlsafe`). Хеш — тот же bcrypt основного
  приложения (`app.core.security.get_password_hash`), логин сразу работает. Нет админа → None.
- **Роут** `POST /super/companies/{id}/reset-password` (под `require_super_admin`):
  сброс → рендер формы компании с баннером «Новый пароль для {email}: … (скопируйте,
  больше не покажем)». Кастомный пароль <6 → ошибка.
- **UI**: карточка «Сброс пароля администратора» на странице редактирования компании
  (поле для своего пароля или авто-генерация, confirm перед сбросом). Пароль показывается
  один раз, не уходит в URL/лог.

⚠️ Суперадмин — отдельный сервис (profiles:[superadmin]); пересобран на VPS вручную
(`docker compose --profile superadmin build superadmin && up -d superadmin`).
