# v1.5.0 — Персональные OAuth-токены рекрутёров hh (2026-08-13)

Проблема: вся компания смотрела/писала под ОДНИМ общим hh-OAuth → все резюме
«просмотрены мной» и общий суточный лимит 500 просмотров выжигался одним человеком.

- Каждый рекрутёр подключает СВОЙ hh-аккаунт. Интерактив (чат/поиск/просмотры/
  автоподбор/забор контакта) идёт под ЛИЧНЫМ токеном инициатора → его лимит и
  атрибуция персональны; нет личного → фолбэк на общий компанийный.
- Гард работодателя: личный аккаунт обязан быть менеджером работодателя компании.
- Каскад квоты просмотров: личные 500/сут исчерпаны → добираем из общего.
- Модель `UserHhIntegration`, `HhOauthState.kind`, селектор `get_hh_token_for_user`.
  Миграции `f0a1b2c3d4e5` + `a1c2e3f4b5d6`. API `/hh/authorize/me` `/hh/me/status` `DELETE /hh/me`.
- Фон/кроны остаются на общем токене.
