# v1.6.5 — Фикс отказа на hh (правильный URL discard) (2026-08-14)

Проблема: отказ на hh не проходил, письмо кандидату не уходило.

- Корень: клиент слал `PUT /negotiations/discard_by_employer` с `topic_id` в ТЕЛЕ, а hh
  требует id отклика в ПУТИ: `PUT /negotiations/discard_by_employer/{nid}`. Без id в
  пути hh не привязывал запрос → 403 resume_not_found → discard падал, а письмо шлётся
  только после успешного discard → тоже не уходило.
- Исправлен URL (id в пути). Закрытые вакансии (пустой actions[], hh не даёт отклонить)
  больше не ретраятся вечно — помечаются обработанными.
