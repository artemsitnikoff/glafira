# v1.7.4 — Talantix: разовая джоба бэкфилла резюме у пустых кандидатов (2026-08-15)

Дополнение к v1.7.3. После фикса новые Talantix-кандидаты приходят с полным резюме,
но ~1.5k, залитых ДО фикса (+ те, что skip пропустил), остались с пустым резюме.

- **Новая джоба** `app/jobs/backfill_talantix_resumes.py` (штатный модуль с логами,
  как остальные джобы — `[talantix]`-логи видны). Берёт ТОЛЬКО `source='talantix'`
  без структурного опыта, перезапрашивает резюме с Talantix и дозаливает опыт/навыки/
  зарплату тем, у кого они есть; у кого на Talantix реально нет опыта — оставляет как
  есть. Potok/hh/прочие НЕ трогает. Идемпотентно (перед вставкой ещё раз проверяет
  отсутствие опыта). Параллелит (semaphore, дефолт 6), пачками по 300.
- Использует существующие `mapper.map_person` + `_create_talantix_child_records` (та же
  логика, что в импорте) — единый источник правды, без дублирования маппинга.
- Разовая, НЕ крон. ⚠️ Не запускать поверх идущего импорта Talantix (спор за OAuth-токен).

**Запуск (VPS, разово):**
```
cd /var/www/glafira && docker compose -f docker-compose.prod.yml run --rm backend \
  python -m app.jobs.backfill_talantix_resumes 2>&1 | tee -a talantix-backfill.log
```
Опц. `TALANTIX_BACKFILL_LIMIT=100` (проба), `TALANTIX_BACKFILL_CONCURRENCY=6`.
