# 13 — Вакансии: «мои / остальные» и разводящая

## Проблема
Когда активных вакансий много, плоский список в сайдбаре нечитаем: свои вакансии теряются среди чужих, а зайти «посмотреть всё» некуда — раздел «Вакансии» без выбранной вакансии показывал пустую заглушку.

## Что сделано

### 1. Модель: у вакансии есть ответственный
В `VACANCIES` добавлены поля: `owner` (ФИО рекрутера), `dept`, `city`, `days` (дней в работе), `hired`, `positions`. Текущий пользователь — константа `ME = 'Анна Седова'` (в проде — id из сессии).

Демо-состав: Анна Седова — 6 вакансий, Иван Корнев — 4, Ольга Реброва — 2 (это рекрутеры-коллеги, ФИО показываются полностью).

### 2. Сайдбар: группировка
Подсписок «Вакансии» сверху вниз:
- **Заявки** (+N новых) — вход жизненного цикла, см. док 12;
- **Все вакансии N** — переход на разводящую;
- «Новая вакансия», поиск;
- группа **МОИ** — вакансии, где `owner == ME` (счётчик в заголовке группы);
- разделитель, свёрнутая группа **ОСТАЛЬНЫЕ N** — по клику раскрывается; при вводе в поиск раскрывается сама, чтобы поиск шёл по всем вакансиям;
- разделитель, **Архив**.

### 3. Разводящая «Все вакансии»
Отдельный экран (`allVacanciesActive`), собран на разметке Архива — одна визуальная система:
- `archive-head`: заголовок + «6 моих из 12 активных» / «Показано N из 12»;
- `filter-bar`: группа «Ответственный» (сегмент Мои / Все / ФИО коллег), группа «Отдел», поиск, «Сбросить», «Новая»;
- `archive-grid` из `arch-card`: бейдж «В работе», бейдж «+N новых», название, `отдел · ответственный`, `в работе N дней · город · заявка №N` (если вакансия создана по заявке), статистика «кандидатов» и «нанято X из Y»;
- в режиме «Все» карточки разбиты на группы «Мои · 6» и «Другие рекрутеры»;
- клик по карточке открывает вакансию (воронка кандидатов).

### 4. Побочные правки
- `VACANCY_INFO` в Candidates.jsx достраивается из `VACANCIES`: раньше вакансии вне четырёх захардкоженных открывались с заголовком «Frontend-разработчик» (фолбэк). Теперь любая вакансия открывается со своим названием, городом и ответственным.
- В `primitives.jsx` добавлены иконка `grid` и размер аватара `xs`.

## Правила
- «Мои» = `owner == текущий пользователь`; вакансии коллег доступны для просмотра, но по умолчанию скрыты под «Остальные».
- Поиск в сайдбаре ищет по всем вакансиям (обе группы), группировка сохраняется.
- Разводящая — не замена сайдбару: сайдбар для быстрого переключения между своими, разводящая для обзора и поиска по всей компании.
- Счётчик «Все вакансии» = активные вакансии, без архива.

## Вне скоупа (обсудить)
- Реальные права: видеть чужие вакансии / только свои — настройка роли.
- Сортировка на разводящей (по новым кандидатам, по дням в работе, по SLA).
- Избранные / закреплённые вакансии в сайдбаре.
- Пометка «просрочена» на карточке по дедлайну заявки.
