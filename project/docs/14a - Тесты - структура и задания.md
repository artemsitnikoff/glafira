## ТЕСТ 1. «ЛОГИКА» (матрицы)
- Заданий 20, время 18 минут на весь тест (ОБЩИЙ таймер), матрица 3×3 (правая нижняя ячейка пустая), 8 вариантов, возврат запрещён (только вперёд), по нарастанию сложности.
- Правила (Carpenter, Just & Shell 1990): CR (constant in a row), PP (quantitative pairwise progression), A/S (figure addition/subtraction: union/subtraction/XOR), D3 (distribution of three, латинский квадрат), D2 (distribution of two — самое трудное).
- Атрибуты: shape: circle|square|triangle|hexagon|diamond|star; fill: empty|hatch-h|hatch-v|dots|solid; size: S|M|L; count: 1|2|3; rotation: 0|45|90|135|180; lines: vert|horiz|diag-l|diag-r|arc-top|arc-bottom.
- ⚠️ ЦВЕТ НЕ ИСПОЛЬЗУЕТСЯ (только ч/б геометрия), формат ячейки shape/fill/size/count/rot, прочерк — атрибут не задействован.

### Блок A (1–4, 1 правило)
A1 PP(size): r3 triangle/empty/S, triangle/empty/M → ОТВЕТ triangle/empty/L. Дистракторы: triangle/empty/S · triangle/empty/M · circle/empty/L · square/empty/L · triangle/solid/L · triangle/empty/L/rot180 · diamond/empty/L
A2 CR(shape)×PP(fill): r3 triangle/empty, triangle/hatch-h → ОТВЕТ triangle/solid
A3 PP(count): r3 star×1, star×2 → ОТВЕТ star×3
A4 D3(shape) латинский квадрат: r3 triangle, circle → ОТВЕТ square

### Блок B (5–10, 2 правила)
B5 D3(shape)×D3(fill): shape r3[triangle circle ?], fill r3[solid empty ?] → ОТВЕТ square/hatch-h
B6 A/S union (линии): r3 [vert]+[diag-r] → ОТВЕТ [vert,diag-r]. Дистракторы: [vert] · [diag-r] · [vert,diag-l] · [horiz,diag-r] · [vert,horiz,diag-r] · [vert,diag-r]+лишняя точка · пустая
B7 A/S subtraction: r3 [horiz,diag-l,diag-r]−[horiz] → ОТВЕТ [diag-l,diag-r]
B8 A/S XOR: r3 [diag-l,horiz]⊕[horiz,arc-bottom] → ОТВЕТ [diag-l,arc-bottom]
B9 PP(rotation)×CR(shape): r3 key/90, key/135 → ОТВЕТ key/180
B10 PP(size)×PP(count) встречное: r3 triangle/L×1, triangle/M×2 → ОТВЕТ triangle/S×3

### Блок C (11–16, 2–3 правила)
C11 D3(shape)×D3(fill)×CR(size): r3 [triangle/solid/L, circle/empty/L, ?] → ОТВЕТ square/hatch-h/L
C12 A/S union × D3(фон): r3 c1=[vert]/фон-dots, c2=[arc-top]/фон-empty → ОТВЕТ [vert,arc-top]/фон-hatch-v
C13 PP(count)×D3(shape)×PP(size): r3 [hexagon×1/L, diamond×2/M, ?] → ОТВЕТ star×3/S
C14 XOR×D3(rotation): r3 c1=[vert,horiz]/rot180, c2=[horiz]/rot0 → ОТВЕТ [vert]/rot90
C15 D2 (внутр. dot/cross/—): внутр r3[—, dot, ?], внешняя circle → ОТВЕТ circle/cross
C16 D2×PP(size): r3 [square/—/S, square/dot/M, ?] → ОТВЕТ square/cross/L

### Блок D (17–20, 3+ правила, макс. сложность)
D17 A/S union × PP(rotation) × CR(fill): r3 c1=[vert]/rot0/hatch-h, c2=[diag-r]/rot45/hatch-h → ОТВЕТ [vert,diag-r]/rot90/hatch-h
D18 D3(shape)×D3(fill)×PP(count)×CR(size): r3 [hexagon/solid×1/M, star/empty×2/M, ?] → ОТВЕТ diamond/hatch-v×3/M
D19 D2×D3(shape)×PP(size): r3 [triangle/—/S, hexagon/dot/M, ?] → ОТВЕТ circle/cross/L
D20 XOR×D2×PP(rotation): r3 c1=[vert,horiz]/dot/rot0, c2=[horiz]/—/rot45 → ОТВЕТ [vert]/cross/rot90

### Типы дистракторов (7 на задание, по одному каждого)
1 Repetition (копия соседней ячейки) · 2 Difference (ответ с одним изменённым атрибутом) · 3 Incomplete correlate (правило частично, M вместо L) · 4 Wrong principle (продолжена другая закономерность) · 5 Matrix construction (элемент не из той позиции) · 6 Union error (лишний/недостающий элемент при A/S) · 7 Random.
