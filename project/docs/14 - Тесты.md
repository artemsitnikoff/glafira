# 14 — Тесты

Модуль тестов способностей: кандидат проходит тест по ссылке (как сотрудник — пульс-опрос), рекрутёр настраивает, назначает и разбирает результат внутри Глафиры.

Файлы: `Тесты - кандидат.html` (публичные экраны), `components/Tests.jsx`, `styles/tests.css`.

## Часть 1. Публичные экраны кандидата

Отдельная страница без авторизации и без сайдбара приложения. Layout и токены — как в «Форме заявки»: марка 👩🏻, белая карточка 16px на светлом фоне. Десктоп и мобильная версия (брейкпоинт 720px). Слева — демо-переключатель экранов и состояний таймера (только для просмотра, в проде его нет).

**1. Старт.** Название теста, число заданий и минут, предупреждение про непрерывный таймер. Блок «Как проходить» — 4 пункта. Обучающий пример: мини-матрица 3×3 с подставленным верным ответом и объяснением правила. Чекбокс согласия 152-ФЗ обязателен — до него кнопка «Начать тест» неактивна.

**2. Задание-матрица** (тест «Логика»). Верхняя полоса: название · прогресс «Задание 7 из 20» с полоской · таймер справа. Матрица 3×3 в рамке, правая нижняя клетка — пунктир и «?». Ниже 8 вариантов (4×2 на десктопе, 2×4 на мобиле), состояния: обычный / hover-подъём / выбранный (акцентная рамка + тинт). «Далее» активна только после выбора. Обратной связи о правильности нет нигде.

**3. Задание-текст** (тест «Структура интеллекта»). Двухуровневый прогресс: «Блок 2 из 4 · Аналогии» + «Задание 5 из 15», таймер блока. Форматы задания: аналогия, числовой ряд (моноширинный), исключение слова. Ответы — 5 строк-радиокарточек с буквами а–д, высота строки ≥52px. Внизу «Назад» / «Пропустить» / «Далее» — внутри блока переход свободный.

**4. Заставка блока.** Название блока, инструкция в 2–3 строки, разобранный пример, время на блок. Таймер стартует по кнопке; пауза между блоками не ограничена.

**5. Время истекло.** Мягкая модалка поверх приглушённого задания: сколько успел, «ответы сохранены», что дальше. Кнопка «Продолжить».

**6. Завершение.** Галочка, «Тест завершён», результат передан рекрутёру. Баллы и верные ответы кандидату не показываются — только затраченное время мелким шрифтом.

**7. Служебные состояния.** Срок ссылки истёк · тест уже пройден (с датой) · соединение потеряно (таймер идёт, автопереподключение).

### Таймер
Единственный элемент, меняющий цвет: тёмный при >3 мин → оранжевый 3–1 мин → красный с мягкой пульсацией <1 мин. Моноширинный, tabular-nums, формат 12:34.

### Правила оформления заданий
Матрицы и варианты — чёрно-белая геометрия, тонкие линии, три состояния заливки (пусто / штриховка / сплошная). Цвет в самих заданиях не используется: он не должен нести смысл. Тон текстов — поддерживающий («отвечайте вдумчиво»), без давления.

## Часть 2. Экраны рекрутёра

**8. Каталог (Настройки → Тесты).** Две секции: «Отдельные тесты» и «Наборы». Карточка теста: иконка, название, тип, состав, длительность, статус (активен / черновик), «назначен N×». Действия: «Предпросмотр» (открывает публичную страницу), «Настроить», копирование ссылки. Набор — несколько тестов одной ссылкой (напр. «HR-менеджер: Логика + Структура интеллекта»).

**9. Настройка теста.** Общее (название, тип, число заданий, длительность, тумблеры «перемешивать варианты» и «разрешить возврат»). Блоки — список с временем на каждый и перетаскиванием порядка, итог по заданиям и минутам. Пороги — пять категорий со светофорными метками и числовыми границами. Автоматика — автоотправка на выбранном этапе воронки и автоотказ ниже порога.

**10. Назначение теста** — модалка из карточки кандидата. Выбор теста или набора, срок действия ссылки в днях, канал (Telegram / e-mail / WhatsApp, предпочтительный помечен), редактируемый шаблон сообщения. После отправки — «Ссылка отправлена, ожидаем прохождения».

**11. Результат — вкладка «Тесты» в карточке кандидата.** Крупный балл «17 / 20», цветная категория, дата и время из лимита. Профиль по блокам — горизонтальные бары (сильные зелёные, слабые жёлтые). Перцентиль по накопленной базе. Оранжевая плашка «Результат может быть недостоверен» с причиной (слишком быстро / обратный градиент сложности / не завершён). Раскрывающаяся таблица «Ответы по заданиям»: № · ответ · верно/неверно · время. Если тест назначен, но не пройден — статус, «Напомнить», «Отменить». Если не назначен — пустое состояние с кнопкой.

**12. Тест в воронке (экран 03).** Колонка «Тест» между «Датой отбора» и «Этапом»: плашка с баллом в цвете категории, «⏳ ожидаем» для отправленных, «—» для неназначенных. В drawer фильтров — секция «Результат теста»: чипы Неважно / Пройден / Ожидаем / Не назначен + слайдер минимального балла.
