## 2. Опыт работы — раскладка как на hh.ru

### Сетка одного места работы (`.job`)
Две колонки: **слева — сроки**, справа — содержание.

```
┌──────────────┬──────────────────────────────────────────────┐
│ 2023-02 —     │ ООО «Атом Безопасность» (Staffcop)           │ ← компания (якорь, жирный)
│   2024-07     │ Информационная безопасность, разработка ПО   │ ← сфера компании (серый)
│              │ Руководитель группы прямых продаж            │ ← должность (полужирный)
│ 1 год 5 мес   │ – работа с воронкой продаж группы            │ ← пункты с чёрточками «–»
│              │ – анализ воронки и составление прогноза…     │
│              │ – …                                          │
└──────────────┴──────────────────────────────────────────────┘
```

**Порядок в правой колонке (важно):** название компании → строка о сфере → должность → обязанности.

### Иерархия (по ТЗ: компания = якорь, сфера/должность ниже)
| Элемент | Размер / вес | Цвет |
|---|---|---|
| Компания (`.job-co`) | 15px / 700, `letter-spacing:-0.01em` | `--fg-1` |
| Сфера (`.job-sphere`) | 12.5px / 400 | `--fg-3` |
| Должность (`.job-title`) | 14px / 600 | `--fg-1` |
| Сроки (`.job-period`) | 13px / 400 | `--fg-2` |
| Стаж (`.job-dur`) | 12.5px / 400 | `--fg-3` |
| Пункт (`.job-bullets li`) | 13.5px, line-height **1.38** | `--fg-1` |

Маркер пункта — чёрточка `–` (en dash) через `::before`, цвет `--fg-3`. **Не точки.**

### CSS
```css
.job {
  display: grid;
  grid-template-columns: 134px 1fr;
  column-gap: 22px;
  padding: 13px 0;
  border-top: 1px solid var(--border-2);
}
.job:first-of-type,
.cc-sec-title + .job { border-top: 0; padding-top: 2px; }

.job-when   { grid-column: 1; padding-top: 1px; }      /* сроки слева */
.job-period { font-size: 13px;   color: var(--fg-2); line-height: 1.4; }
.job-dur    { font-size: 12.5px; color: var(--fg-3); margin-top: 3px; }

.job-main   { grid-column: 2; min-width: 0; }
.job-co     { font-size: 15px; font-weight: 700; color: var(--fg-1); letter-spacing: -0.01em; line-height: 1.3; }
.job-sphere { font-size: 12.5px; color: var(--fg-3); margin-top: 2px; line-height: 1.35; }
.job-title  { font-size: 14px; font-weight: 600; color: var(--fg-1); margin-top: 5px; line-height: 1.3; }

.job-bullets { margin: 6px 0 0; padding: 0; list-style: none; display: flex; flex-direction: column; gap: 2px; }
.job-bullets li { position: relative; padding-left: 16px; font-size: 13.5px; line-height: 1.38; color: var(--fg-1); text-wrap: pretty; }
.job-bullets li::before { content: '–'; position: absolute; left: 2px; top: 0; color: var(--fg-3); }

/* подзаголовок внутри обязанностей (напр. «Управление бизнесом:») */
.job-bullets li.job-subhead { padding-left: 0; margin-top: 5px; font-weight: 600; color: var(--fg-1); }
.job-bullets li.job-subhead::before { content: none; }
```

> Плотность: межстрочный интервал пунктов 1.38, отступ между пунктами 2px — сознательно стянуто.

### Модель данных (`RESUME_JOBS`)
```js
{
  role:   'Руководитель группы прямых продаж',   // должность
  co:     'ООО «Атом Безопасность» (Staffcop)',   // компания (якорь)
  sphere: 'Информационная безопасность, разработка ПО', // строка о сфере
  period: '2023-02 — 2024-07',                    // сроки (как в исходном резюме)
  dur:    '1 год 5 мес',                          // стаж
  items: [                                        // обязанности
    'работа с воронкой продаж группы',
    { h: 'Управление бизнесом:' },                // объект {h} = подзаголовок-группа
    'определение стратегии развития…',
  ],
}
```
- Опыт выводится **полностью**, без обрезки до N пунктов.
- Длинные места работы (напр. «Управляющий директор») делятся подзаголовками `{h:'…:'}`.
