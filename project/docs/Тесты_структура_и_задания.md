# ТЕСТ 1. «ЛОГИКА» (матрицы)

## Параметры

| Параметр | Значение |
|---|---|
| Заданий | 20 |
| Время | 18 минут на весь тест (общий таймер) |
| Формат задания | матрица 3×3, правая нижняя ячейка пустая |
| Вариантов ответа | 8 |
| Возврат к заданиям | запрещён (только вперёд) |
| Прогрессия | по нарастанию сложности |

Аналог Standard Progressive Matrices (60 заданий, 5 серий A–E). Сжато до 20 заданий / 18 минут для скрининга, все пять правил покрыты.

## Правила построения (Carpenter, Just & Shell, 1990)

| Код | Правило | Суть |
|---|---|---|
| **CR** | Constant in a row | Значение атрибута постоянно в строке, меняется между строками |
| **PP** | Quantitative pairwise progression | Количественная прогрессия по строке (размер, число, поворот) |
| **A/S** | Figure addition/subtraction | Третья ячейка = сумма / разность / XOR первых двух |
| **D3** | Distribution of three | Три значения распределены по строке (латинский квадрат) |
| **D2** | Distribution of two | Два значения + «пустое»; самое трудное правило |

Сложность = число одновременных правил × нагрузка на рабочую память.

## Атрибуты элементов

```
shape:    circle | square | triangle | hexagon | diamond | star
fill:     empty | hatch-h | hatch-v | dots | solid
size:     S | M | L
count:    1 | 2 | 3
rotation: 0 | 45 | 90 | 135 | 180
lines:    vert | horiz | diag-l | diag-r | arc-top | arc-bottom
```

## Банк заданий

Формат ячейки: `shape/fill/size/count/rot`. Прочерк — атрибут не задействован.

### Блок A — 1 правило (задания 1–4, разминка)

**A1** — PP(size)
```
r1: circle/empty/S    circle/empty/M    circle/empty/L
r2: square/empty/S    square/empty/M    square/empty/L
r3: triangle/empty/S  triangle/empty/M  ?
```
Ответ: `triangle/empty/L`
Дистракторы: triangle/empty/S · triangle/empty/M · circle/empty/L · square/empty/L · triangle/solid/L · triangle/empty/L/rot180 · diamond/empty/L

**A2** — CR(shape в строке) × PP(fill)
```
r1: circle/empty    circle/hatch-h    circle/solid
r2: square/empty    square/hatch-h    square/solid
r3: triangle/empty  triangle/hatch-h  ?
```
Ответ: `triangle/solid`

**A3** — PP(count)
```
r1: circle×1  circle×2  circle×3
r2: square×1  square×2  square×3
r3: star×1    star×2    ?
```
Ответ: `star×3`

**A4** — D3(shape), латинский квадрат
```
r1: circle    square    triangle
r2: square    triangle  circle
r3: triangle  circle    ?
```
Ответ: `square`

### Блок B — 2 правила (задания 5–10)

**B5** — D3(shape) × D3(fill), сдвиги разные
```
shape:  r1[circle square triangle]  r2[square triangle circle]  r3[triangle circle ?]
fill:   r1[empty hatch-h solid]     r2[hatch-h solid empty]     r3[solid empty ?]
```
Ответ: `square/hatch-h`

**B6** — A/S union (линейные элементы). c3 = объединение c1 и c2
```
r1: [vert] + [horiz] = [vert,horiz]
r2: [diag-l] + [diag-r] = [diag-l,diag-r]
r3: [vert] + [diag-r] = ?
```
Ответ: `[vert, diag-r]`
Дистракторы: [vert] · [diag-r] · [vert,diag-l] · [horiz,diag-r] · [vert,horiz,diag-r] · [vert,diag-r]+лишняя точка · пустая

**B7** — A/S subtraction. c3 = c1 минус элементы c2
```
r1: [vert,horiz,diag-l] − [diag-l] = [vert,horiz]
r2: [arc-top,vert,diag-r] − [diag-r] = [arc-top,vert]
r3: [horiz,diag-l,diag-r] − [horiz] = ?
```
Ответ: `[diag-l, diag-r]`

**B8** — A/S XOR. c3 = элементы, встречающиеся ровно в одной из c1, c2
```
r1: [vert,horiz] ⊕ [horiz,diag-l] = [vert,diag-l]
r2: [arc-top,vert] ⊕ [vert,diag-r] = [arc-top,diag-r]
r3: [diag-l,horiz] ⊕ [horiz,arc-bottom] = ?
```
Ответ: `[diag-l, arc-bottom]`

**B9** — PP(rotation) × CR(shape)
```
r1: arrow/0   arrow/45   arrow/90
r2: flag/45   flag/90    flag/135
r3: key/90    key/135    ?
```
Ответ: `key/180`

**B10** — PP(size) × PP(count), встречное
```
r1: square/L×1    square/M×2    square/S×3
r2: circle/L×1    circle/M×2    circle/S×3
r3: triangle/L×1  triangle/M×2  ?
```
Ответ: `triangle/S×3`

### Блок C — 2–3 правила (задания 11–16)

**C11** — D3(shape) × D3(fill) × CR(size в строке)
```
size:  r1=S, r2=M, r3=L (постоянен в строке)
shape: латинский квадрат, сдвиг +1
fill:  латинский квадрат, сдвиг +2
r3: [triangle/solid/L, circle/empty/L, ?]
```
Ответ: `square/hatch-h/L`

**C12** — A/S union × D3(фон ячейки)
```
Линии складываются, фон ячейки распределён латинским квадратом (empty/dots/hatch-v).
r3: c1=[vert]/фон-dots, c2=[arc-top]/фон-empty → ?
```
Ответ: `[vert,arc-top]/фон-hatch-v`

**C13** — PP(count) × D3(shape) × PP(size)
```
count: 1,2,3 по столбцам
shape: латинский квадрат
size:  L,M,S по столбцам
r3: [hexagon×1/L, diamond×2/M, ?]
```
Ответ: `star×3/S`

**C14** — XOR × D3(rotation)
```
Линии по XOR; поворот фигуры распределён 0/90/180 латинским квадратом.
r3: c1=[vert,horiz]/rot180, c2=[horiz]/rot0 → ?
```
Ответ: `[vert]/rot90`

**C15** — D2 (распределение двух значений) — ключевое трудное правило
```
Внутренний элемент принимает значения dot / cross / отсутствует,
в каждой строке и столбце ровно один пропуск.
внутр.: r1[dot, cross, —]  r2[cross, —, dot]  r3[—, dot, ?]
внешняя фигура: circle везде
```
Ответ: `circle/cross`

**C16** — D2 × PP(size)
```
D2 на внутреннем элементе; размер внешней фигуры растёт по строке.
r3: [square/—/S, square/dot/M, ?]
```
Ответ: `square/cross/L`

### Блок D — 3+ правила (задания 17–20, максимальная сложность)

**D17** — A/S union × PP(rotation) × CR(fill)
```
Линии складываются; результат повёрнут на +45° относительно c2; заливка постоянна в строке.
r3: c1=[vert]/rot0/hatch-h, c2=[diag-r]/rot45/hatch-h → ?
```
Ответ: `[vert,diag-r]/rot90/hatch-h`

**D18** — D3(shape) × D3(fill) × PP(count) × CR(size) — четыре правила
```
r3: [hexagon/solid×1/M, star/empty×2/M, ?]
```
Ответ: `diamond/hatch-v×3/M`

**D19** — D2(внутренний элемент) × D3(shape) × PP(size)
```
r3: [triangle/—/S, hexagon/dot/M, ?]
```
Ответ: `circle/cross/L`

**D20** — XOR × D2 × PP(rotation)
```
r3: c1=[vert,horiz]/dot/rot0, c2=[horiz]/—/rot45 → ?
```
Ответ: `[vert]/cross/rot90`

## Типы дистракторов

Для каждого задания — 7 неверных вариантов, по одному каждого типа:

1. **Repetition** — копия соседней ячейки (c2 или r2c3)
2. **Difference** — верный ответ с одним изменённым атрибутом
3. **Incomplete correlate** — правило применено частично (размер M вместо L)
4. **Wrong principle** — правдоподобно, но продолжена другая закономерность
5. **Matrix construction** — элемент из неправильной позиции матрицы
6. **Union error** — при A/S: лишний или недостающий элемент
7. **Random** — комбинация атрибутов, не встречающаяся в матрице

Порядок вариантов ответа **рандомизируется при каждом прохождении**.

# МЕТОДИКА РАСЧЁТА

## Сырой балл

Каждое верное задание = **1 балл**, частичных баллов нет.

- Тест «Логика»: 0–20
- Тест «Структура интеллекта»: блоки 0–15 / 0–15 / 0–15 / 0–12; сумма 0–57

## Чего делать НЕЛЬЗЯ

**Не показывать «IQ = 118».** Перевод сырого балла в IQ требует нормировочной выборки. У оригинальных методик нормы куплены вместе с тестом; у собственных заданий их нет по определению. Цифра IQ без норм — выдумка, и она же — прямой юридический риск при споре об отказе.

## Что показывать вместо этого

**Этап 1 — до накопления данных (первые ~30 кандидатов).**
Сырой балл + время + разбивка по блокам:

```
Логика                     14 / 20    16 мин 20 сек из 18:00
Структура интеллекта       41 / 57
  Исключение слова         12 / 15
  Аналогии                 11 / 15
  Числовые ряды             9 / 15
  Обобщение                 9 / 12
```

Плюс профиль — какой блок сильнее/слабее относительно остальных. Это работает без норм, потому что сравнение внутрииндивидуальное.

**Этап 2 — собственные нормы (от 100+ прохождений).**
Перцентиль по накопленной базе компании:

```
percentile = (кандидатов с баллом ниже / всего кандидатов) × 100
```

Формулировка: `14 / 20 — выше, чем у 78% кандидатов`. Честно и юридически защитимо: сравнение с реальной популяцией соискателей, а не с чужой нормой.

**Этап 3 — привязка к успешности (от 30+ нанятых с оценкой работы).**
Корреляция балла с оценкой руководителя через 3–6 месяцев. Даёт: (а) реальный порог отсечения вместо интуитивного, (б) обоснование «деловых качеств» на случай спора.

## Категории для быстрого чтения (интерим)

Тест «Логика», 20 заданий / 18 минут:

| Сырой балл | Категория | Метка |
|---|---|---|
| 17–20 | Высокий | 🟢 |
| 13–16 | Выше среднего | 🟢 |
| 9–12 | Средний | 🟡 |
| 5–8 | Ниже среднего | 🟠 |
| 0–4 | Низкий | 🔴 |

Границы **пересмотреть** после накопления собственных данных — это стартовые ориентиры, не норма.

## Проверка достоверности

(Аналог consistency check в оригинальной методике Равена.)

Флаг «результат ненадёжен», если:

- **Слишком быстро** — среднее время на матрицу < 15 сек (случайные клики)
- **Обратный градиент** — в блоке D (17–20) правильных больше, чем в блоке A (1–4); статистически маловероятно, признак угадывания или подсказки
- **Не завершено** — пропущено > 25% заданий по таймауту
- **Аномальная ровность** — все ответы в одной позиции (везде 1-й вариант)

При флаге рекрутёру показывается плашка «Результат может быть недостоверен: <причина>», а не голый балл.

## Хранение

- Ответы — по заданиям (id задания, выбранный вариант, время на задание): нужно для пересчёта норм и анализа
- Результат привязан к **Application** (кандидат + вакансия), т.к. один кандидат участвует в нескольких вакансиях
